# Security policy

Do not report security issues through public issues or discussions, especially if they could expose financial records, OAuth tokens, or API keys.

Use the repository's private security-reporting channel when it is enabled. Until then, contact the maintainer privately through the repository profile.

For the local companion's access and browser-origin security requirements, see [Local companion: Access and snapshot lifetime](docs/local-companion.md#access-and-snapshot-lifetime).
